# 🛒 OrderApp

A dynamic web application designed to simulate a real-world ordering system. This project was developed as a hands-on exercise during my Web Development training at **Developer Akademie**, focusing on modern JavaScript, clean data architecture, and responsive UI design.

### 🚀 Key Features
* Dynamic product rendering from structured JavaScript data/objects
* Interactive cart logic and status management
* Modular code structure built for scalability

### 🛠️ Tech Stack
* HTML5 / CSS3
* JavaScript (ES6+)
